Simple Platformer Game 🎮

About the Game

This is a simple platformer game created as a practice project to learn and improve my game development skills. The game features a player who can move and jump across platforms while collecting stars.

The game also includes a score system and a Game Over screen. Players can restart the game and try again.

Purpose

The purpose of this project is to practice creating a game and learn the basic concepts of game development, including player movement, jumping, collision detection, scoring, and game restart mechanics.
